# 🎯 AI Interview Simulator

An AI-powered interview preparation platform that helps users practice technical and HR interviews through dynamically generated questions and intelligent answer evaluation.

## 🚀 Features

* 🤖 AI-generated interview questions
* 📝 Real-time answer submission
* 📊 AI-based answer evaluation and scoring
* 💡 Personalized feedback and improvement suggestions
* 🎚️ Multiple difficulty levels (Easy, Medium, Hard)
* 📚 Support for different interview domains and topics
* 🔄 Fallback question bank for uninterrupted experience
* 🌐 Responsive and user-friendly interface

## 🔍 How It Works
1. User selects interview topic and difficulty.
2. AI generates an interview question.
3. User submits an answer.
4. Gemini AI evaluates the response.
5. The system returns:
   * Score
   * Strengths
   * Weaknesses
   * Suggestions for improvement
